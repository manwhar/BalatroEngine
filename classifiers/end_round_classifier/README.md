# `end_round_classifier` — Temporal `END_ROUND` Detection Workspace

Detects the implicit **`END_ROUND`** moment (`calculate_joker({end_of_round = true})` in Balatro's scoring/cleanup flow) within variable-length `[PLAY_HAND, CASH_OUT]` video segments cropped strictly to the central `play_area` (`G.play`, `1920x1080` reference ROI `x=518.70, y=421.04, w=1034.46, h=287.46` -> resized to `256x72` at `15.0 FPS`).

Excluding the right-hand screen region prevents streamer facecams, Twitch chats, and deck/burn overlays from biasing predictions.

---

## Workspace Layout

- `config.py` — Shared constants (`STATES`, `PLAY_AREA_ROI`, `256x72` size, `15 FPS`, loss/Viterbi hyperparameters).
- `schema.py` — `ClipMeta` / `ClipEvents` contract and `build_frame_targets()` mapping sparse Lua events or real-VOD timestamps into per-frame 4-state segmentation labels + Gaussian boundary targets (using `IGNORE_INDEX = -100` where unannotated).
- `video_io.py` — ROI scaling, BGR/RGB conversion, and sequential `cv2.VideoCapture` segment resampling.
- `sync_dataset.py` — Pulls `<clip_id>/meta.json` folders from `%APPDATA%\Balatro\Mods\gamestate_dataset_cv\dataset_end_round` (or `balatro_mod/dataset_end_round`) into `dataset/raw/` while preserving `dataset/real_vod/`.
- `prepare_dataset.py` — Converts raw mod clips (`raw_rgb_u8`, `raw_rgba_u8`, `png_seq`, `video`) and `real_vod/` clips into compact `dataset/prepared/clips/*.pt` tensors + `manifest.json`.
- `temporal_augmentations.py` — Clip-consistent spatial misalignment, color/compression/blur/noise jitter, smooth Bezier `cursor.png` trajectories, and safe duration stretching/trimming (`augment_sequence_length`).
- `dataset.py` — `EndRoundClipDataset` (run-grouped stratified train/val split, RAM caching, `end_round`-preserving long-sequence cropping) and `collate_end_round_batch`.
- `model.py` — `TemporalEndRoundNet` (pretrained `mobilenet_v3_small` / `mobilenet_v3_large` / `resnet18` evaluated strictly on unpadded frames -> horizontal `AdaptiveAvgPool2d((1, 6))` -> dilated TCN stem -> packed BiGRU -> 4-state head + boundary head) + exact monotonic 4-state Viterbi decoder (`decode_monotonic_viterbi` + `predict_end_round_index`).
- `train.py` — Masked multi-task training loop with CUDA AMP (`bfloat16`/`float16`), cosine LR decay, frame-error validation metrics, curves, and confusion matrix plots.
- `evaluate.py` — Split benchmarking (`MAE`, `median`, `P90`, `<=1f/<=2f/<=3f`, worst failure timeline plots) and single-video segment debugging (`--video`).
- `pipeline.py` — `EndRoundRecognitionPipeline` exposing `predict_video_segment()`, `predict_frames()`, `predict_tensor()`, and `predict_batch()` for `post_processing.py`.

## CLI Workflow

Run from repo root or `classifiers/end_round_classifier/`:

```powershell
# 1. Pull raw clips generated by the Balatro mod
py -m classifiers.end_round_classifier.sync_dataset

# 2. Preprocess raw + real_vod clips into .pt sequence tensors
py -m classifiers.end_round_classifier.prepare_dataset

# 3. Train model (CUDA AMP enabled automatically when GPU is available)
py -m classifiers.end_round_classifier.train --epochs 30 --batch-size 0

# Or sync + prepare + train in one command:
py -m classifiers.end_round_classifier.train --sync --prepare

# 4. Evaluate validation set and inspect worst errors
py -m classifiers.end_round_classifier.evaluate --split val

# 5. Inspect a real VOD segment directly
py -m classifiers.end_round_classifier.evaluate --video path\to\vod.mp4 --start-ts 124.2 --end-ts 136.5 --plot-out debug_timeline.png
```

### Recommended Hook Design in Balatro Lua / Love2D

1. **Pre-crop & pack `raw_rgb_u8` (`256x72`)**: Capturing only the `G.play` ROI cropped and downscaled directly in Love2D before writing sequential bytes to `frames.bin` (`num_frames * 72 * 256 * 3` bytes ≈ 4 MB per clip) avoids writing tens of thousands of tiny PNG files on NTFS and cuts disk I/O by >10x.
2. **Exact Ground-Truth Event Captures**:
   - `play_hand_frame`: Start sampling at `15.0 FPS` when `G.FUNCS.play_cards_from_highlighted` triggers (or 0.25s before, inside `PRE_PLAY`).
   - `first_card_in_play_frame`: First sampled frame where `#G.play.cards > 0`.
   - `draw_to_discard_frame`: Sampled frame index when `G.FUNCS.draw_from_play_to_discard` fires.
   - **`end_round_frame`** (**required**): Sampled frame index when `end_round()` / end-of-round joker pass (`calculate_joker({end_of_round = true})`) executes. Supervise this directly from the engine event rather than heuristics—at `4x` game speed, `end_round()` can fire just before the sliding card animations finish leaving the box.
   - `cards_cleared_frame`: Optional diagnostic index when every previously played card's visual center `VT.x` clears the right edge of `G.play`.
   - `round_eval_enter_frame` / `round_eval_settled_frame`: When `G.STATE == G.STATES.ROUND_EVAL` starts and when the Cash Out / round eval UI settles (`round_eval` container finishes tweening).
3. **Real VOD Hard-Example Drops (`dataset/real_vod/`)**:
   Put manually timed VOD slices in `classifiers/end_round_classifier/dataset/real_vod/<clip_id>/` using `"frame_format": "video"`, `"already_cropped": false`, `"source": "real_vod"`, `"source_start_frame"`, `"source_end_frame"`, and only `"events": { "end_round_frame": <frame_offset_in_segment> }`. Unannotated frames default to `IGNORE_INDEX = -100` for state CE loss while still training the Gaussian boundary spotting head cleanly.

## Future `post_processing.py` Hook API

Once weights are trained and placed at `weights/end_round_best.pt` (or `classifiers/prod_weights/end_round_classifier.pt`):

```python
from classifiers.end_round_classifier import EndRoundRecognitionPipeline

end_round_pipe = EndRoundRecognitionPipeline()  # auto-loads weights & CUDA AMP
res = end_round_pipe.predict_video_segment(
    video_path,
    start_frame=play_hand_action.frame_idx,
    end_frame=cash_out_action.frame_idx,
)
# res.end_round_frame      -> exact source video frame index
# res.end_round_timestamp  -> exact seconds in source video
# res.confidence           -> [0, 1] confidence for thresholding / fallback
```
