# Telemetry Regression Test Corpus

This directory stores real-gameplay Balatro telemetry logs (`.jsonl`) generated by the `gamestate_dataset_cv` mod during live play or test suite runs.

## Purpose
- **Edge-Case Accumulation:** Each archived `.jsonl` file records a full closed-loop run (actions, card states, shop offerings, deck mutations, and joker interactions).
- **Automated Regression Testing:** Tests in `testing/test_engine.py` and `testing/test_engine_parity.py` automatically discover and validate the engine against every run in this directory to guarantee zero discrepancies across all known edge cases.

## Usage
- **Archive active run from Balatro:**
  ```bash
  python testing/test_engine_parity.py --archive
  ```
- **Test all accumulated runs:**
  ```bash
  python testing/test_engine_parity.py --all
  ```
- **Clear the archive:**
  ```bash
  python testing/test_engine_parity.py --clear-archive
  ```

> [!WARNING]
> **Schema Invalidation / Migration Notice:**
> The `--clear-archive` hook should ONLY be executed whenever the underlying structure or schema of `run_telemetry.jsonl` fundamentally changes (e.g. telemetry event format changes, breaking state schema updates, or card structure redesign) such that legacy logs would be incompatible with new systems.
